# AGENT OS — Professional Specialist Prompt Library

A local-first directory of professional specialist prompts. Browse roles across 16 disciplines, copy complete master prompts into ChatGPT or another AI assistant, build custom specialist profiles, and maintain a personal Prompt Vault.

**This is not an autonomous AI agent platform.** It does not execute models, connect to Ollama, call AI APIs or orchestrate tasks.

## Start
Open `index.html` in a modern browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features
- 160 specialist role prompts across 16 professional disciplines.
- Search, department filters, favourites and recent profiles.
- Full master prompt preview and one-click copy.
- Custom specialist Prompt Workshop.
- Full-text Prompt Vault.
- IndexedDB persistence and JSON backup/restore.

## Local-first
No Supabase, external database, account service, AI API or paid backend. Data remains in the browser profile. Use Backup & Restore to move a copy of the library between devices.
